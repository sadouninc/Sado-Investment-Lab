title: ACSL vs Terra Drone — 成長・資本・売上の質を比較 as_of: 2026-08-13 —

このページは企業研究の読み取り専用比較です。 勝敗、売買判断、推奨数量を生成しません。ACSL = 国策型、Terra Drone = グローバル型 は比較のための見方であり永久ラベルではありません。未確認事項は 未確認 / 未検証 のまま扱います。

30秒で見る核心

ACSL（6232）国内政府調達と国家研究開発が主な成長エンジン。政府資金・官需を売上・粗利・キャッシュフローへ変換し、増資への依存を下げられるかが核心。
Terra Drone（278A）海外市場、無人機交通管理（UTM）、サービス、M&A、提携網が主な成長エンジン。大型成長投資と希薄化を上回る利益・キャッシュフロー創出へ転換できるかが核心。

共通の未解決点: 両社とも、現在の成長投資・政策追い風が構造的な利益・フリーキャッシュフローへ変換されたとはまだ確認できません。

同じ軸で比較

成長エンジン

ACSL国内政策 / 官需 / 国家研究開発 / 国産化。
Terra Drone海外市場 / 無人機交通管理（UTM） / ドローンサービス / 海外契約・提携。

資本の使い方

ACSL政府の研究開発支援・調達が民間の資本負担を代替し、希薄化への依存を下げられるか。
Terra Drone株式調達資金をM&A・海外展開・防衛へ投下し、希薄化以上の企業価値を作れるか。

売上の質

ACSL防衛・官需の具体的な受注見通しが強み。保守・運用支援が継続収益化するかは要検証。
Terra Drone無人機交通管理（UTM） / SaaS / 点検 / ライセンスなど継続収益の選択肢がある。全社利益への変換はまだ未検証。

最大の上昇材料

ACSL防衛調達の継続・大型化、粗利・キャッシュフロー改善、政府資金から自立収益化への接続。
Terra Drone海外大型契約、無人機交通管理（UTM）の継続収益拡大、防衛分野での事業拡大、海外事業基盤の収益化。

最大のリスク

ACSL官需集中、計画遅延、赤字継続、再度の増資。
Terra Drone海外事業の実行遅延、M&A統合の遅れ、希薄化、利益化遅延、事業構造の複雑化。

読み違え防止

  • ACSLは国内専業ではありません。 海外展開も存在するため、「国策型」は主要な成長エンジンの比重を示す研究ラベルです。
  • Terra Droneも政策と無関係ではありません。 日本・欧州で防衛・政府案件が拡大しており、グローバル型と政策恩恵は両立します。
  • 政策依存度が高いことを自動的に悪材料とは評価しません。政府の研究開発支援や調達が民間資本負担を減らすなら資本効率改善要因になり得ますが、実際の自立収益化は根拠で確認します。

成長エンジン — 何が売上を増やすか

ACSL

政府の研究開発支援 → 国産・安全なドローン技術 → 政府調達 → 機体・保守・運用支援 → 売上・粗利 → キャッシュフロー、という流れを確認しています。

確認済み研究では、2026年防衛省納入予定の開示受注拡大、政府研究開発、国内安全保障政策との接続が主要根拠です。ただし 政府資金が確認できたことと、自立した黒字企業になったことは同義ではありません。

Terra Drone

海外事業基盤 → インフラ・点検・無人機交通管理の顧客接点 → プラットフォーム・サービス・防衛連携 → 継続ライセンスと機体・サービス機会 → 利益・キャッシュフロー、という流れを確認しています。

サウジアラビアの石油・ガス、国家レベルの無人機交通管理、海外港湾運用、海外販売・提携網など、海外展開の幅が成長エンジンの特徴です。防衛も追加の成長エンジンとして拡大中ですが、現在の全社営業赤字を解消したとは扱いません。

資本の使い方 — 成長を誰の資本で作るか

ACSL — 政府支援が希薄化低下へつながるか

政府の研究開発支援と官需が開発費・需要の双方を支えることで、将来の増資依存を下げられる可能性があります。一方、自立収益化・構造的黒字化は未確認です。

見る指標:

  • 営業キャッシュフロー / フリーキャッシュフロー
  • 現預金残高
  • 政府調達の継続性
  • 粗利率 / 限界利益率
  • 新たな増資の有無

Terra Drone — 株式調達による世界展開が希薄化を上回るか

研究では大型の株式調達をM&A・海外展開・防衛事業へ振り向ける構造が確認されています。論点は「希薄化があるか」だけではなく、調達資本1円が将来の売上・粗利・キャッシュフロー・企業価値をどれだけ増やすかです。

見る指標:

  • 調達資金の用途と消化状況
  • M&A / 海外投資後の追加売上・粗利
  • 継続収益比率
  • 営業キャッシュフロー / 現金消費
  • 希薄化率に対する企業価値・利益成長

売上の質 — 売上の継続性と利益変換

ACSL

  • 現時点では政府調達の具体的な受注見通しが比較上の強み。
  • 保守・運用支援・システム統合へ広がる余地あり。
  • 防衛案件の粗利率、継続保守比率、複数年度の継続調達は 未確認 / 要確認。

Terra Drone

  • 機体だけでなく、無人機交通管理（UTM） / SaaS / 点検 / ライセンスを持つことが継続収益の選択肢。
  • 防衛向けUTMなど、初期契約後の継続ライセンスが成立すれば売上の質が改善する余地。
  • ただし全社・UTM事業の収益性は現時点で 未検証。継続収益が全社利益を押し上げる規模に達したとは断定しません。

上昇材料とリスクを対で追う

ACSL

上昇材料

  • 防衛の継続受注・調達拡大
  • 政府支援研究から商用粗利への変換
  • キャッシュフロー改善
  • 継続保守・運用支援比率の上昇

リスク / 仮説崩壊の監視点

  • 調達集中の悪化、計画遅延
  • 売上増でも粗利・キャッシュフローが改善しない
  • 継続的な希薄化が再発
  • 政策追い風が受注・利益へ転換しない

Terra Drone

上昇材料

  • 海外大型契約の積み上がり
  • 無人機交通管理（UTM） / ライセンスの継続収益拡大
  • 海外防衛連携の受注化
  • M&A / 投資後の利益率・キャッシュフロー改善

リスク / 仮説崩壊の監視点

  • 海外売上拡大に対して赤字・現金消費が長期化
  • M&A統合遅延
  • 株式調達による価値創出が希薄化に追いつかない
  • 多地域・多事業化で実行難度が上昇
