# BOJ Early Warning System Data

Owner: 🌅アサヒ (Asahi)  
Contract: `data/contracts/boj-early-warning-v1.schema.json`

## Purpose

Operational data store for BOJ (Bank of Japan) rate hike risk early warning system.

This system provides **explainable early warning** for portfolio holdings exposure to BOJ policy normalization risk. It does NOT auto-generate BUY/SELL orders. Final decisions remain with Owner Authority.

## Files

### `signal_state.json`
Current BOJ policy risk signal state: GREEN / ORANGE / RED

**State definitions:**
- **GREEN**: Weak evidence of imminent rate hike
- **ORANGE**: Multiple indicators (inflation ↑, hawkish breadth ↑, market pricing ↑, JPY/JGB pressure)
- **RED**: PRIMARY evidence of imminent hike (BOJ officials/statements explicitly signal next meeting hike OR actual policy decision)

**CRITICAL**: Market probability alone CANNOT trigger RED. RED requires primary BOJ evidence.

### `portfolio_sensitivity.json`
Portfolio holdings mapped to BOJ sensitivity profiles. Generated by `scripts/boj_portfolio_sensitivity.py`.

Each holding includes:
- `rate_sensitivity`: LOW / MEDIUM / HIGH / UNKNOWN
- `yen_sensitivity`: BENEFIT / NEUTRAL / HEADWIND / MIXED / UNKNOWN
- `energy_input_sensitivity`: LOW / MEDIUM / HIGH / UNKNOWN
- `valuation_duration`: LOW / MEDIUM / HIGH / UNKNOWN
- `balance_sheet_rate_risk`: LOW / MEDIUM / HIGH / UNKNOWN
- `boj_risk_action`: HOLD / WATCH / REDUCE_CANDIDATE / EXIT_REVIEW

### `market_evidence.json` (optional)
Market-implied BOJ policy expectations:
- Next meeting hike probability
- JGB yields (2Y, 5Y)
- OIS rates
- USD/JPY

### `primary_evidence.json` (optional)
BOJ primary policy evidence archive:
- MPM statements
- Summary of Opinions
- Outlook Reports
- Governor/Board member speeches

## State → Action Mapping

| Signal State | Action |
|--------------|--------|
| **GREEN** | HOLD - No action from BOJ factor alone |
| **ORANGE** | HIGH sensitivity → WATCH<br>REDUCE_CANDIDATE only with overlapping Market Phase/event risk |
| **RED** | HIGH sensitivity → REDUCE_CANDIDATE review<br>EXIT_REVIEW only with thesis invalidation + liquidity/leverage risk |

**Important**: Actions are review triggers, NOT automatic sell orders.

## Company Sensitivity Evidence

Company-specific sensitivity profiles stored in:
```
data/research/boj_sensitivity/{ticker}.json
```

**Evidence requirements:**
- Must use company IR/financial disclosures
- Cannot infer from sector/industry name alone
- Missing data returns UNKNOWN (fail-closed)
- SHORT positions handled with inverse logic

Example evidence sources:
- Latest securities report (有価証券報告書)
- Financial results briefings (決算短信)
- Debt structure disclosures
- Management guidance

## Integration Points

1. **Market Weather / Money Flow (#42系)**: Consumes JGB/FX/rate context
2. **Intraday Market Refresh (#444)**: Consumes meaningful delta signals
3. **Morning Portfolio Check (#46)**: Projects BOJ action candidates (read-only)
4. **Canonical Portfolio**: `data/portfolio/current.json` (SSoT for holdings)

## Operational Rules

1. **No automatic trading**: System generates review candidates only
2. **Fail-closed for UNKNOWN**: Missing company evidence → HOLD action
3. **RED gate**: Market probability alone insufficient for RED
4. **SHORT positions**: Separate treatment, no mechanical increases
5. **Owner approval**: Final decision authority remains with portfolio owner
